# 💛 Graça Divina — Catálogo Digital

Aplicação web desenvolvida para a loja **Graça Divina**, com o objetivo de digitalizar a consulta de produtos e facilitar o gerenciamento do catálogo e do estoque.

O projeto foi desenvolvido para atender a uma necessidade real de um comércio local, proporcionando maior organização dos produtos e praticidade no atendimento aos clientes.

## ✨ Funcionalidades

### 🛍️ Catálogo público
- Visualização dos produtos disponíveis.
- Apresentação visual dos produtos com fotografias.
- Canal de contato para demonstrar interesse nos produtos.

### 🔐 Painel administrativo
- Autenticação das administradoras.
- Acesso à área administrativa.
- Cadastro de produtos.
- Edição das informações dos produtos.
- Gerenciamento de disponibilidade e estoque.
- Organização dos produtos cadastrados.

### 📊 Área financeira
- Área administrativa destinada ao acompanhamento de informações financeiras da loja.

## 🎨 Interface e experiência do usuário

- Layout responsivo para dispositivos móveis e desktops.
- Identidade visual baseada na proposta da loja.
- Utilização de componentes do Ant Design.
- Organização da navegação entre as áreas pública e administrativa.
- Interface desenvolvida com CSS.

## 🗄️ Armazenamento e autenticação

A aplicação utiliza os serviços do Firebase para gerenciamento dos dados e autenticação das administradoras.

O Cloud Firestore permite armazenar e consultar os produtos cadastrados, enquanto o Firebase Authentication controla o acesso à área administrativa.

## 🌐 Deploy

A aplicação está publicada utilizando Firebase Hosting.

**Acesse o projeto:** [Graça Divina](https://gracadivina-2d199.web.app/)

## 🎯 Objetivo do projeto

Desenvolver uma solução digital para auxiliar a loja Graça Divina na organização de seus produtos, facilitando a consulta do catálogo pelos clientes e o gerenciamento do estoque pelas administradoras.

O desenvolvimento proporcionou a aplicação prática de conhecimentos em desenvolvimento web, construção de interfaces com React, gerenciamento de rotas, integração com serviços Firebase, autenticação e manipulação de dados.
